# Data

This folder contains the source CSV files used for the WOMart sales forecasting workflow.

| File | Purpose |
| --- | --- |
| `TRAIN.csv.csv` | Historical training data with store, region, date, holiday, discount, order, and sales fields. |
| `TEST_FINAL.csv.csv` | Forecasting input data without the final sales target. |
| `SAMPLE.csv.csv` | Sample submission format with `ID` and `Sales` columns. |

The files keep their original names from the project source material for traceability.
